# roblox-item-finder-beta-2.0
NEW UPDATE INCLUDES ---  Search and check, Item checker, Duplicate skipping, Pause, stop, and resume, Proxy tools Scrape, import, test, and manage proxies; monitor their health, rotate after errors, and refill the pool automatically, Request controls, Saved results and history, Exports, Statistics, Rolimon’s tools, Settings, Diagnostics, Interface 


Catalog search: Search by keywords, with saved keyword presets and batch loading from a word list.

Search and check: Collect catalog asset IDs and check them in one run.

Item checker: Check a list of asset IDs against filters for price, item type, and limited status.

Duplicate skipping: Skip IDs already saved so searches can reach new results.

Pause, stop, and resume: Save progress and continue interrupted searches or checks.

Proxy tools: Scrape, import, test, and manage proxies; monitor their health, rotate after errors, and refill the pool automatically.

Request controls: Set request speed, throttle requests through each proxy, and cool down proxies after rate limits.

Saved results and history: Store items and price observations in SQLite; keep search history and resume checkpoints.

Exports: Export results and proxy health as CSV or JSON.

Statistics: View saved result and price-history statistics.

Rolimon’s tools: Look up player values, check item data, log item observations, and chart observations collected by the app.

Notifications: Configure Discord webhook notifications and desktop or sound notifications.

Settings: Choose the results folder, startup tab, proxy behavior, request speed, and other preferences.

Diagnostics: Check connection status and report HTTP responses.

Interface: Use a multi-tab window with file dialogs and background work.
